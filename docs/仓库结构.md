## 四、体检发现的问题

### P1｜`covers/` 是死资产（最严重）
- 1,384 张图，**280.8 MB**，占仓库 98%；
- 全部集中在 **2026-08（1,374 张）与 2026-09（10 张）**；
- **在 `index.html`/`dashboard.html`/`map.html` 中被引用数 = 0**（实测逐文件名匹配）；
- 无重复图（MD5 去重后仍 1,384 张）。

→ 结论：**旧封面生成方案的遗留**，当前站点不使用。它让 clone 变慢、Pages 体积变大、git 历史膨胀。

### P2｜生成产物直接入库
- `index.html`（1.44 MB）+ `assets`（1.44 MB）+ `news.json`（1.46 MB）每天被覆盖提交；
- 好处：Pages 部署简单；代价：每次提交都在 git 里存一整份，历史会持续变大。

### P3｜缺 `.gitignore`
- 仓库根目录没有 `.gitignore`，临时文件（`_tmp/`、`output/` 等）容易误入库。

### P4｜文档分散
- `README.md` 讲站点，`来源.md` 讲上游管线和生成方式，两者内容有重叠；
- 新加的 `docs/methodology/` 在 README 里没有入口。
