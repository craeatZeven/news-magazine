# 全球粮食形势与粮食危机风险评估

> 分析日：2026-11-17 ｜方法：《新闻分析框架 v1.0》七步。
> 一句话结论：**全球性"断供型"粮食危机概率不高（约 10–15%），但"高价 + 局部饥荒"已经在发生，且未来 12 个月会加深。**

---

## 一、先定义：三种不同的"粮食危机"

| 类型 | 表现 | 当前状态 |
|---|---|---|
| **价格危机** | 国际粮价翻倍、进口国付不起 | 高位，但未失控（FFPI 比 2022 峰值低 16.4%） |
| **可获得性危机** | 出口禁令、断供、贸易中断 | 局部（黑海航运），未全球化 |
| **饥荒** | IPC 第 5 阶段，大规模死亡 | **已发生**（苏丹部分地区） |

**不定义清楚，"会不会有粮食危机"这个问题无法回答**——因为答案取决于你问的是哪一种。

---

## 二、事实层（按信源分级）

### T1/T2：价格与供需（FAO，2026-11-06 发布）

| 指标 | 数值 |
|---|---|
| FAO 食品价格指数（10 月） | **133.9**，环比 -1.2%，同比 **+5.9%**，比 2022 年 3 月峰值低 **16.4%** |
| 谷物价格指数 | 环比 **-4.5%**（小麦四连涨后回落，阿根廷增产、黑海预期缓和） |
| 2026 年全球谷物产量 | **29.99 亿吨**，历史第二高（低于 2025 纪录） |
| 谷物库存 | 期末 **+1.8%**；库存消费比 **32.4%**，略高于上年 |
| 谷物贸易 | **-3.3%** 至 5.077 亿吨（小麦 -8.6%） |
| 大米 | 产量 **5.52 亿吨（-2.5%）**，四季来首次下降（厄尔尼诺 + 种植收益差） |

### T2：世界银行/USDA（2026-10 Commodity Markets Outlook，11-12 博客）

| 指标 | 数值 |
|---|---|
| 全球谷物供应（产量+期初库存） | **-2000 万吨**（四年来首次下降） |
| 玉米库存消费比 | **21.5%**，2012/13 以来最低（但远高于 2010/11 的 13.2%） |
| 小麦 / 大米 / 食用油库存消费比 | 34% / 37.2% / **12.5%（2009/10 以来最低）** |
| 食品价格指数 | 9 月创三年新高，10 月回落但仍 **同比 +15%** |
| 预测 | 2026 **+10%**、2027 **+7%**；极端情形比基准再高 12%，**超过 2022 年峰值** |
| 2026Q3 谷物价格 | 环比 **+9%**（玉米 +8%、小麦 +13%） |

### 人道侧（WFP 2026 Global Outlook，2026-01）

- **3.18 亿人**处于危机级（IPC 3+）或更严重；数十万人处于饥荒级条件；
- 严重粮食不安全人数：2021 年 8.37 亿 → 2025 年 **7.79 亿**（粮价下跌带来的改善）；
- WFP 资金到位**不足需求一半**；苏丹部分地区已确认饥荒。

### 驱动因素

1. **黑海**：对港口与航运的袭击（小麦、玉米、葵油出口）；
2. **强厄尔尼诺**：亚洲稻米、南美玉米受威胁；
3. **出口国干旱**：美国小麦产量 **-23%**（1970/71 以来最低），乌克兰出口 **-18%**；
4. **生物燃料需求**：印尼棕榈油掺混 B40→B50、美国生物燃料配额，食用油库存消费比压到 12.5%；
5. **化肥**：今年涨约 20%，2026–27 预计回落，但霍尔木兹若中断可再涨 30%。

## 三、框架对照：同一组数据，三套叙事

| 叙事 | 定义的问题 | 归因 | 药方 | 省略 |
|---|---|---|---|---|
| **FAO（供应派）** | 供应充足、价格回落 | 需求疲软、阿根廷增产 | 无需恐慌 | 库存"卖不出去"的结构问题 |
| **世界银行/USDA（紧缩派）** | 库存收紧、风险上行 | 冲突 + 厄尔尼诺 + 生物燃料 | 警惕价格上行 | 分配与贫困问题 |
| **人道机构（灾难派）** | 已发生的饥荒 | 冲突 + 资金缺口 | 紧急援助 | 宏观供需 |

**关键分歧点**：FAO 说库存消费比 32.4%、还上升；世界银行说玉米 21.5%、十年最低。
两个都对——**因为 FAO 的库存里含俄乌"积压库存"**（原文：出口受阻导致库存堆积）。**库存上升不等于可动用供给上升**，这是最容易被误读的一处。

## 四、三个互斥假设与判别证据（ACH）

| 证据 | H1 全球断供型危机 | H2 高价+局部饥荒 | H3 平稳 |
|---|---|---|---|
| 谷物产量仍为历史第二高 | 不一致 | 一致 | 一致 |
| 玉米库存消费比 21.5%（低位） | 一致 | 一致 | 不一致 |
| 贸易量仅 -3.3%（未断） | 不一致 | 一致 | 一致 |
| 苏丹已确认饥荒 | 一致（领先指标） | 一致 | 不一致 |
| 尚无大规模出口禁令潮 | 不一致 | 一致 | 一致 |
| 价格同比 +5.9%~+15%，非翻倍 | 不一致 | 一致 | 一致 |

**判定**：**H2 最一致（置信度 ★★★★）**；H1 的"冒烟枪"（出口禁令潮 + 价格翻倍）尚未出现；H3 被库存低位与厄尔尼诺否定。

## 五、机制链

**条件**：库存偏低（玉米 21.5%）+ 强厄尔尼诺 + 生物燃料挤压食用油 + 能源价格。
→ **触发**：黑海袭击升级 / 主产国出口禁令 / 南美或亚洲极端天气。
→ **放大**：出口限制扩散、恐慌性采购、运费与保险上涨、援助资金缺口。
→ **转折**：南美与黑海丰收、厄尔尼诺转弱、政策协调（如黑海走廊）。

**反事实**：若 10 月没有阿根廷增产与黑海缓和预期，FFPI 不会环比 -1.2%——说明**当前是"脆弱平衡"，不是"趋势恶化"**。

## 六点五、化肥：这次分析最初漏掉的一环（2026-11-17 补）

**为什么重要**：化肥是粮食的"上游投入品"，价格冲击会**滞后 1–2 季**传导到单产。粮价危机常是"化肥先涨、粮食后涨"。

**事实（世界银行 2026 年 4 月 Commodity Markets Outlook）**：

| 指标 | 数值 |
|---|---|
| **霍尔木兹海峡中断** | 约 **1/3 的全球贸易化肥量**退出市场 |
| 尿素价格（2026 年 3 月） | **725.6 美元/吨**，环比 **+53.7%**，四年最高 |
| DAP（磷酸二铵） | 658.3 美元/吨（+5%） |
| MOP（氯化钾） | 380.6 美元/吨 |
| 化肥价格指数 | 自 2025Q4 以来 **+12%** |
| 2026 全年预测 | 尿素均价 **+约 60%**；DAP +6%；MOP +12%；2027 回落 |
| 风险情形 | 若霍尔木兹中断持续，2026 年化肥价格 **再涨 30%+** |

**传导链**：

`霍尔木兹/LNG + 氨 → 尿素成本 → 农民施肥量下降（可负担性） → 下一季单产下降 → 玉米/小麦/水稻供给收缩 → 粮价`

**关键放大器：可负担性**。世界银行的"化肥/作物价格比"仍在 2022 年前水平之上——**粮价高但化肥更贵时，农民会少施肥**，这比价格本身更伤产量。

**政策变量**：
- 中国出口限制（2024 年氮肥出口一度 -90%，2025 上半年延续，后期尿素出口回升）；
- 白俄罗斯钾肥受欧盟制裁；欧盟对俄/白化肥加税；
- 中东出口改道陆路，部分抵消海峡风险。

**对结论的影响**：化肥把"价格危机"的概率往上推，也让"2027 年粮食供给"比 2026 年更紧——**这是最容易被忽略的时间差**。
## 七、预测（12 个月，含概率与判据）

| 情形 | 概率 | 判据 |
|---|---|---|
| **H2 基准：高价震荡 + 局部饥荒加深** | **60–65%** | FFPI 在 130–160 区间，个别国家出现确认饥荒 |
| H3 缓和：价格回落、库存重建 | 15–20% | 厄尔尼诺转弱 + 黑海复航 + 化肥回落 + 丰收 |
| **H1 全球断供型危机** | **12–18%** | 出口禁令潮（≥5 国）+ FFPI 连续 3 月 >160 + 贸易量降幅 >8% + **化肥再涨 30%** |
| 极端情形（世行 adverse） | 8–12% | 价格超过 2022 峰值 |

**结论**：**不会出现 2007–08 或 2022 年那种全球性价格失控的概率较高；但"局部饥荒 + 高价"是现在进行时，且援助资金缺口是放大器。**

## 八、观察信号（按优先级）

1. **FFPI 连续 3 个月 >145**，且谷物分项 >150；
2. **出口限制数量**：新增 ≥5 国（IFPRI/Food Security Portal 追踪器）；
3. **黑海战争险费率与运费**：是否再次跳升；
4. **厄尔尼诺（ONI）**：是否维持 >1.5 到 2027 年春季；
5. **玉米库存消费比**：是否跌破 20%；
6. **WFP 资金缺口**：是否超过 60%（决定饥荒是否扩大）；
7. **化肥**：尿素是否站稳 700 美元/吨以上、DAP 是否再涨；霍尔木兹是否复航；
8. **化肥/作物价格比**（可负担性）：是否继续恶化（决定农民少施肥）。

---

## 九、边界与不确定性

- 数据口径差异：FAO（全部谷物，含积压库存）vs USDA（分品种、可动用库存），结论方向不同属正常；
- 厄尔尼诺强度预测本身有误差；
- 黑海局势属政治事件，不可用趋势外推；
- 本分析未覆盖：中国/印度库存细节、各国出口政策文本、期货持仓结构。
