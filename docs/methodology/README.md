## 核心主张

1. **新闻只呈现一个切面**——分析的任务是补齐切面、标出省略；
2. **信源分三级**（一手/二手/三手）——三手只提供线索，不提供事实；
3. **框架拆解看五样**：定义问题、归因、道德评价、药方、**省略**；
4. **先写互斥假设，再读评论**——顺序反了，框架就是别人的；
5. **概率要记账**——没有台账，就永远不知道自己准不准。

## 两个必须遵守的边界

- **口径先行**：同一指标不同机构方向可以相反（库存含不含积压、计票时点不同），不对齐不许下结论；
- **据报 ≠ 事实**：只有三手源的结论，正文必须写"据报/据称"。
