# 新闻分析框架 v1.0（可执行版）

> 这份是**操作手册**，不是理论报告。理论依据见《新闻分析方法论-从切面到人民视角》；逐篇原文见《新闻分析-核心文献笔记》。
> 配套空表：`模板-新闻分析五表.md`。一次完整分析约 3–5 小时。

---

## 0. 适用与不适用

**适用**：有明确事件、有公开报道、需要在数小时内形成可核查判断的场合（写稿、决策、复盘）。
**不适用**：纯预测（无事实基础）、纯价值争论（无事实分歧）、以及只有单一信源且无法交叉的事件（此时只能写"据报"）。

---

## 1. 总览（七步，按顺序做，不许跳）

```
第 0 步 定锚       → 时间锚 / 主体锚 / 争议锚
第 1 步 盘点       → 信源分级 T1/T2/T3 + 缺口表
第 2 步 框架       → 四功能 × 四位置 × 省略 + 类型选择
第 3 步 地图       → 产业链 / 制度链 / 人物链 / 利益相关方
第 4 步 假设       → ACH 矩阵 + 四种证据检验
第 5 步 机制       → 条件 / 触发 / 放大 / 转折 + 反事实
第 6 步 影响       → 分层影响 + 成本受益 + 观察信号
```

---

## 第 0 步｜定锚（30 分钟）

**动作**：
1. **时间锚**：最早一篇报道是哪天？此前有没有伏笔（更早的报道/传闻）？
2. **主体锚**：谁被讨论、谁在行动、谁是第三方？
3. **争议锚**：争的是事实（发生了什么）、归因（为什么）、还是立场（该不该）？

**产出**：一句话定义 + 一张时间轴草表。
**失败模式**：把旧闻当新闻（例：把 2025-04 的 H20 事件当成 2026-11 的辞职事件）。

---

## 第 1 步｜材料盘点与信源分级（1 小时）

**动作**：
1. 列出所有相关材料，标 T1/T2/T3：
   - **T1 一手**：公告、8-K、判决书、原始数据、当事人声明、会议记录
   - **T2 二手**：通讯社、权威媒体基于一手源的报道
   - **T3 三手**：评论、转述、自媒体、主播
2. 画**缺口表**：哪一格只有 T3？哪一格完全没有？
3. 列**沉默者清单**：应该说话但没说话的人（公司、客户、监管、当事人）。

**产出**：表 A（信源与缺口）。
**铁律**：T3 只能提供**线索**，不能提供**事实**。凡只有 T3 的结论，正文写"据报/据称"。

---

## 第 2 步｜框架拆解（1 小时）

**动作（按顺序）**：
1. **选类型**（de Vreese 2005）：这件事用 **issue-specific**（单事件深挖）还是 **generic**（跨事件比较）？跨案例比较才用后者。
2. **填四功能**（Entman 1993）：**定义问题 → 因果解释 → 道德评价 → 治疗建议**。每一项**引原文一句**，不许概括；并注意原文是"and/or"，允许不齐全。
3. **查四位置**：传播者（谁在框）、文本（关键词/套话/信源）、接收者（受众接不接受）、文化（提供了什么库存）。
4. **列省略**：它没说什么、没引谁、没提哪个数字。**（Entman：多数框架由省略定义，省略可能和呈现同样关键）**
5. **分清两层**（Chong & Druckman 2007）：**frames in communication**（文本里的强调）vs **frames in thought**（受众脑子里的图式）。**没有效果证据，不下效果结论。**
6. **量议程位置**（McCombs & Shaw 1972）：版面、时长、重复次数、是否系列报道——用数字，不用感觉。

**产出**：表 B（框架对照：来源 × 四功能 × 省略 × 议程位置）。
**失败模式**：只做第 2 步的"四功能"，却下第 5 条的效果结论——这是最常见的错误。

---

## 第 3 步｜三张地图与利益相关方（1 小时）

**动作**：
1. **产业链地图**：这件事在产业链的哪个环节？（例：设计—代工—存储—设备—云—模型）
2. **制度链地图**：谁有权做什么？（行政令—部委—国会—法院—监管）
3. **人物链地图**：谁和谁是一条线？（盟友、对手、金主、亲属）
4. **利益相关方表**：想要什么 / 能做什么 / 不能或不愿做什么。

**产出**：三张草图 + 利益相关方表。
**判据**：如果只能画出人物链，说明你还停留在"宫斗"层面，没进结构。

---

## 第 4 步｜假设与判别证据（1 小时）

**动作**：
1. 写 **3 个互斥假设**（必须互相排斥；"会发生政变/会发生骚乱"不算互斥）。
2. 列关键证据，做 **ACH 矩阵**：每格标 一致 / 不一致 / 不适用。
3. 给关键证据标**检验类型**（Collier 2011，源自 Van Evera/Bennett）：
   - 稻草人：支持但不排除他者
   - 环检验：必须通过，否则淘汰
   - 冒烟枪：出现即基本成立
   - 双重决定性：同时确认与排除（社会科学中罕见）
4. 敏感性检验：关键证据若为假，结论是否翻转？

**产出**：表 C（假设矩阵）+ 每个假设的置信度（★1–5）。
**铁律**：**先写假设，再读材料**；顺序反了，你的框架一定是别人的。

---

## 第 5 步｜机制链与反事实（1 小时）

**动作**：
1. 把时间线改写成因果链：**条件 → 触发 → 放大 → 转折 → 结果**。
2. 每一环做反事实：删掉它，结果还会发生吗？
3. 标出哪一环是冒烟枪，哪一环只是稻草人。

**产出**：表 D（机制链）。
**判据**：如果你的机制里"触发"和"条件"混在一起，说明还没想清楚。

---

## 第 6 步｜影响分层与观察信号（1 小时）

**动作**：
1. **分层**：公司 / 行业 / 国家 / 群体（含普通人）。每层给一个**可核指标**（股价、财报、许可、听证）。
2. **成本与受益**：谁承担成本、谁获得租金、谁被代表、谁被消音。
3. **观察信号**：3 个信号 + 1 个**可证伪预测**（含时间窗与判据）。

**产出**：表 E（影响与信号）。
**铁律**：写不出"什么信息出现会让我改变判断"，这段就不是分析，是表态。

---

## 质检清单（交付前逐条过）

1. 时间锚打了吗？会不会是旧闻？
2. 每个事实标了 T1/T2/T3 吗？
3. 有没有把 T3 写成事实？
4. 框架四功能每项都有原文引句吗？
5. 省略表写了吗？（至少 3 条）
6. 区分了 communication frame 与 thought frame 吗？
7. 议程位置有数字吗？
8. 假设互斥吗？至少 3 个吗？
9. 关键证据标了四种检验吗？
10. 机制链里条件和触发分开了吗？
11. 反事实做了吗？
12. 有可证伪预测和推翻条件吗？

> 12 条里缺 3 条以上，不要对外交付。

---

## 常见失败模式

| 失败 | 症状 | 修法 |
|---|---|---|
| 旧闻当新闻 | 没有时间锚，直接分析 | 先查最早报道日 |
| 叙事污染 | 全篇用别人的框架，没有自己的假设 | 第 4 步前不许读评论 |
| 断章取义 | 引用一句话，丢了上下文 | 回逐字稿，带时间戳 |
| 把相关当因果 | 时间在前就当原因 | 做反事实 |
| 文本分析冒充效果分析 | 说"受众被影响"却无证据 | 只写到 communication frame |
| 无边界 | 不给推翻条件 | 加"若 X 出现则结论改" |
